# Gallery · 图鉴

A static page: open `index.html` in a browser, or serve this repository with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`); this repository is published at https://zhgarylu.github.io/claude-video/gallery/.
静态页面：直接用浏览器打开 `index.html`，或用 GitHub Pages 发布本仓库（Settings → Pages → 分支 `main`、目录 `/ (root)`）；本仓库已发布在 https://zhgarylu.github.io/claude-video/gallery/。

- `index.html`: the page (HTML, CSS and JS in one file; fonts from Google Fonts, with system fallbacks).
- `data.js`: generated by `python3 tools/build_gallery.py` from `styleboard/catalog.json`, `styles/added.json` and `gallery/talking-head.json` and `prompts/talking-head/*.md`. Re-run it after adding a style, a demo or a prompt.
- `talking-head.json`: the talking-head demos (titles, layouts, descriptions). Their posters are in `docs/talking-head/`.
- Films: the 18 added styles and the three demos play from this repository's release `films`; the original 43 play from the original project's release (`lemomo-ai/lemo-opuscar`). If a film does not play, the viewer has a download button.
