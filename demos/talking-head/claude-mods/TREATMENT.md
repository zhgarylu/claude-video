# TREATMENT · 《Claude Code 的 mods》口播解说片

风格：Dark Tech Keynote（`styles/dark-keynote/STYLE.md`，全部沿用）
素材：`src/host.mp4`（用户提供的 AI 博主口播，30.08 s，560×752 竖屏，24 fps）
规格：1920×1080，24 fps，约 31.4 s（口播 30.08 s + 收尾 1.3 s），响度 −14 LUFS，无颗粒

## 1. 三个候选结构

**A · 三条清单（口播顺序平铺）。** 每个要点一张卡：面板、拦截、斜杠命令各占一屏，卡片之间用展开/折叠衔接。优点是跟口播最贴；缺点是三屏彼此独立，像三张幻灯片，没有“一个东西在长大”的感觉。

**B · 工作台装配（选这个）。** 开场只有一个空的 Claude Code 窗口，边缘留出三个虚线插槽。口播每讲一个要点，就有一个 mod 装进窗口：先是面板和状态栏（看得见），再是拦截闸门（管得住），再是斜杠命令（用得顺）。结尾那句“直接说，帮我做个 mod”，窗口里当场生成第四个 mod，热重载，整面窗口被光扫亮。画面在讲 mod 是什么：能装进工作台的零件。

**C · 一天的故事。** 一个开发者从早上写到晚上，mod 在不同时刻出手。叙事感强，但口播是功能清单，不是故事；硬套会把 30 秒拖成演示。放弃。

选 B 的理由：口播的主语是“把它变成你自己的工作台”，装配就是这句话的画面；窗口始终在场，镜头可以在同一个物体上推拉，符合关键词风格的“界面本身是主角”。

## 2. 一句话与弧线

**Logline**：一个空的 Claude Code 窗口，被三个 mod 装成了你自己的工作台，最后一句话又造出第四个。

**弧线**：开场（打字出标题，窗口从光标里展开）→ 看得见（面板、状态栏、数字）→ 管得住（危险命令入场，**冻结**，闸门放行不了）→ 用得顺（斜杠命令一句话跑完整个流程，提示音）→ 说一句话造一个 mod（热重载，光扫）→ 收尾（讲者窗口折叠成一个小点，只剩工作台和光标）。

## 3. 参照（只学语法）

- 学：发布会里“讲者画中画 + 界面标注”的版面分配；Linear 一类产品片的吸附网格与单一强调色；数字从乱码滚成真值。
- 不学：任何品牌的界面、字体、旋律和标志。

## 4. 版面

- 1920×1080。左：讲者面板 670×900（口播放大 1.2 倍），圆角、1px 边框，左上角一个随人声跳动的小圆点和五根声纹条。右：内容面板 1072×900，是镜头的取景框。
- 底部居中：字幕胶囊，Noto Sans SC 36px，在讲者面板和内容面板下方。

## 7. 音乐与节拍格

105 BPM，4/4，小节 2.2857 s，格线原点 1.614 s，这样 3.9 / 10.8 / 17.6 恰好落在小节线上（偏差小于 25 ms），终和弦（小节 12，29.05 s）正好落在“马上生效”。调式 D 大调五声（D E F♯ A B）。

- 配器：马林巴（合成）、颤音琴（合成）、合成长音垫、低频正弦脉冲、沙锤。无钢琴弦乐。
- 过程：**叠加**（开场一个音 → 看得见时逐小节加声部）→ **冻结**（15.98–16.40 数字静音）→ **一个和弦**（16.4 之后所有声音进同一个调式）→ **减法**（收尾逐个撤掉，只剩光标的 tick）。
- 两个声音家族：危险命令的声音是散的（失谐几十音分、随机声像、各不同音色）；mod 的声音是一族（毡面 tick、玻璃轻点，全在调式里、居中）。

| 段落 | 底噪 | 主要拟音 | 音乐状态 |

## 9. 字幕与标题

字幕是界面组件：底部居中的深色半透明胶囊，1px 亮边，淡淡投影，Noto Sans SC 500 36px，左侧一个强调色“正在说话”的小圆点；上升 + 淡入约 0.16 s；每条保持 ≥ max(1.8 s, 口播时长 + 0.6 s)。按句意断为 10 条。同时导出 `.srt`。

章标：内容面板左上，等宽小标 `01 / 03` + 64px 汉字标题，一屏一句。

## 10. 与我们的 demo 的区别

没有读 demo 代码。本片：输入是用户的口播而非无声；结构是装配而非“混乱 → 整理”；主元素是工作台窗口而非光标独演；冻结点用在危险命令而非整理动作；收尾是讲者折叠。
