# 填空模板：任何风格的“讲者世界”

把【尖括号】里的内容换成你的。关键是：**世界里的东西都是空白的**（没有字、没有标志），文字、数字、引线由后期按风格画；**讲者的动作按口播分段**，每两三句之间留一段不说话的时间做转场。

```text
参考图中的【人物】，是同一个人、同一张脸、同一套【服装】（全程不换装）。
竖幅 3:4，时长 30 秒，24 帧，固定机位，中景偏全景：讲者占画面高度约一半，站在画面中间偏下。

【场景】
【风格世界的一句话描述，例如：一间极简的纯白摄影棚 / 一座等距小岛 / 一张蓝图工作台】，只有一种点缀色：【颜色】。
空间里有【3–4 个】方方正正的大色块、粗线框或道具，彼此留出站人的空位：【左边是什么】，【右边是什么】，【中间后方是什么】。
地面上有【一条线 / 一串点 / 一条路】，从远处一直延伸到讲者脚边，【它象征什么：时间轴 / 数量 / 路线】。
不要出现任何文字、标志、数字和屏幕上的字，画面里的牌子都是空白的。
光线柔和均匀，没有杂乱的道具。

【动作与口播】（普通话，语速自然偏快，口型清楚，口播不要被打断）
0–5 秒：讲者面对镜头打招呼，【一个点题的手势】。
口播：“【立题：这条视频要讲什么，一句话】”

5–7.5 秒：不说话。讲者【走向 / 指向 / 看向】【某个道具】，再回到画面中间。

7.5–13 秒：讲者伸出一根手指，【配合要点 1 的动作】。
口播：“第一，【要点 1】”

13–14.5 秒：不说话。讲者【移动到下一个位置】。

14.5–20 秒：讲者伸出两根手指，【配合要点 2 的动作】。
口播：“第二，【要点 2】”

20–21.5 秒：不说话。讲者【转场动作】。

21.5–26 秒：讲者伸出三根手指，【配合要点 3 的动作】。
口播：“第三，【要点 3】”

26–30 秒：讲者回到画面中间，面向镜头，表情认真，双手自然下垂。
口播：“【收尾：一句提醒或一个问题】”

【画面要求】
讲者全程在同一个世界里，背景只有【大色块、粗线框、地上的线或点】，保持静止，不要随镜头乱动。
讲者占画面比例不要超过一半。动作从容、清楚，手势要明显，方便后期在旁边加说明。
不要换装，不要戴眼镜，不要出现第二个人，不要出现水印和字幕。
口型和口播对齐，说话声清晰，没有背景音乐。
```

**写法的几条经验**：
- 立题在前 5 秒，收尾留一个问题或一个能带走的动作；整条 30 秒、三个要点最稳。
- 每个要点配“数字手势”（一、二、三根手指），后期的序号落在同一刻。
- 不说话的窗口长 1.3–2.5 秒，让后期有时间转场、换版、挪镜头。
- 事实类题材，口播里用“据报道 / 预计 / 官方称”，别写没有来源的数字。
- 生成的道具常有错误（日历日期、屏幕上的字）。先看抽帧再做后期，错的地方在预处理帧里修，并如实说明。
