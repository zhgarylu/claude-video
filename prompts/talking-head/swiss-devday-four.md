# DevDay 2026 开发者四件事（Swiss Motion）

这条还没有拿去生成。内容是 2026-09-29 OpenAI DevDay 面向开发者的四点：Agents API 公测并支持电脑操作、GPT-6.1 Sol 价格约为 Astra 的五分之一、Codex 云端环境、常驻智能体 Dots。来自 InfoQ、Business Standard、OpenAI 开发者社区的汇总，具体 token 价格和上下文长度各家说法不一，口播里没写，发布前请对官方 changelog。

```text
参考图中的男博主，是同一个人、同一张脸、同一套日常休闲上衣（全程不换装）。
竖幅 3:4，时长 30 秒，24 帧，固定机位，中景偏全景：博主占画面高度约一半，站在画面中间偏下。

【场景】
一间极简的纯白摄影棚，墙面和地面是干净的浅灰白，只有一种点缀色：信号绿。
空间里有四块方方正正的大色块和粗黑线框，像瑞士海报的网格，从左到右依次排开，每块之间留出站人的空位：一块绿色竖板，一块黑色横板，一块白色空白方框，一块深灰竖板。
不要出现任何文字、标志、数字和屏幕上的字，画面里的牌子都是空白的。
光线柔和均匀，没有杂乱的道具。

【动作与口播】（普通话，语速自然偏快，口型清楚，口播不要被打断）
0–5 秒：博主面对镜头，抬手打招呼，随后用食指指向自己的头顶，像在说“开发者”。
口播：“9月29日，OpenAI开发者大会，对做开发的人来说，有四件事值得看。”

5–7.5 秒：不说话。博主转向最左边的绿色竖板，抬手一指，再转回正面。

7.5–12.5 秒：博主伸出一根手指，另一只手在空中点几下，像在操作一块看不见的屏幕。
口播：“第一，Agents API进入公测，智能体可以直接操作软件界面。”

12.5–14 秒：不说话。博主向右走一步，站到黑色横板前。

14–18.5 秒：博主伸出两根手指，一只手的掌心向下按，再向下一压，像压低价格。
口播：“第二，GPT-6.1 Sol，价格大约是上一代Astra的五分之一，能力也接近。”

18.5–20 秒：不说话。博主再向右走一步，站到白色空白方框前，抬手做出“展开”的手势。

20–25 秒：博主伸出三根手指，另一只手从身前向远处一推，像把任务发出去。
口播：“第三，Codex能在云端环境里跑，你可以在别的设备上发起远程任务。”

25–30 秒：博主回到画面中间，伸出四根手指，随后双手摊开，面向镜头，表情认真。
口播：“第四，还有常驻智能体Dots。别光看发布，先挑一件，试一下。”

【画面要求】
博主全程在同一个白色棚里，背景只有大色块、粗线框，保持静止，不要随镜头乱动。
博主占画面比例不要超过一半。动作从容、清楚，手势要明显，方便后期在旁边加说明。
不要换装，不要戴眼镜，不要出现第二个人，不要出现水印和字幕。
口型和口播对齐，说话声清晰，没有背景音乐。
```
