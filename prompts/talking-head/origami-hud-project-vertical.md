# 介绍 claude-video 项目（Origami + Sci-fi Hologram，竖屏视频即世界）

这条还没有拿去生成过。两个风格合在一起的做法：世界用科幻全息的语言（近黑舞台、圆形投影台、冰青色发光线框、一点暖色强调），世界里的东西全是折纸造型（折痕线、谷折虚线、山折点划线），就像用光画出来的折纸模型在投影台上折叠和展开。口播不用序号，讲项目的风格库和功能。事实同 README：超过六十种风格、每种有样片、选风格加题材让 AI 导演做成片、口播解说（横屏竖屏）、画廊网站和现成的视频提示词。

```text
参考图中的男博主，是同一个人、同一张脸、同一套日常休闲上衣（全程不换装），身上有一点冷色的轮廓光。
竖幅 9:16（1080×1920），时长 30 秒，24 帧，固定机位，竖屏中景：博主占画面高度约三分之二，站在画面中间。

【场景】
一个近乎纯黑的科幻舞台，博主脚下有一个圆形的投影台：几圈细细的同心圆发光线，一圈亮、一圈虚线，带刻度，慢慢转动。背景是很淡的发光点阵，有轻微的纵深。
整个世界只用一种冷色（冰青色）的发光细线，加唯一的暖色强调：橙色，只在某个东西“确定”的那一刻亮一下。不要实体渲染，所有东西都是发光的线框，线条近亮远暗。
三样东西都是折纸造型，用发光线框画出折痕，都放在画面中间 80% 以内，不要贴到画面边缘：左后方一只发光线框的折纸纸鹤，会慢慢展开成一张平铺的折痕图，再重新折回去；右后方一台发光线框的折纸摄影机，旁边有一个空白的片夹；中间后方一块立着的发光折纸屏幕，屏幕上有虚线的折痕，没有任何内容。
画面最上面约 12% 和最下面约 15% 是干净的黑色，不放任何东西。
不要出现任何文字、标志、数字和屏幕上的字，所有屏幕、片夹和折痕图都是空白的。

【动作与口播】（普通话，语速自然偏快，口型清楚，口播不要被打断）
0–4 秒：博主面对镜头，抬手打招呼，随后把双手在胸前比成一个小方框。
口播：“想用 AI 做视频，又不想千篇一律？我做了一个开源项目，叫 claude-video。”

4–6.5 秒：不说话。博主转头看左边的折纸纸鹤，点点头。

6.5–13 秒：博主一只手向纸鹤一指，纸鹤沿着折痕展开成一张平铺的折痕图，图上的格子一格接一格亮起，每亮一格线条的颜色微微变一下。
口播：“风格库里有水墨、油画、像素游戏、霓虹灯牌、折纸，超过六十种，每一种都有一条用代码做的样片。”

13–14.5 秒：不说话。博主走向右边的折纸摄影机，手放在摇柄上。

14.5–20.5 秒：博主转动摄影机的摇柄；中间的折纸屏幕亮起，屏幕周围展开一圈小小的折纸卡片，像一圈标注框。
口播：“选一个风格，告诉它你的题材，它就导演并做成片；还能做口播解说，在你的讲者视频周围画上标注卡、字幕和配乐，横屏竖屏都行。”

20.5–22 秒：不说话。博主回到画面中间，看着折纸屏幕。

22–26.5 秒：博主做出“翻页”的动作，折纸屏幕像一张纸一样向侧面翻开，露出下一层，再双手递出一小张发光折纸，递向镜头前的人；这时橙色亮了一下。
口播：“还有画廊网站，可以直接看每种风格的样片，现成的视频提示词复制就能用。”

26.5–30 秒：博主面向镜头，表情认真，双手自然下垂。
口播：“项目在我的 GitHub 上。你最想先试哪种风格？”

【画面要求】
博主全程在同一个黑色舞台上，保持在画面中间，走位不超过画面宽度的三分之一，不要离开投影台。
动作从容、清楚，手势要明显，方便后期在两侧加说明。
不要换装，不要戴眼镜，不要出现第二个人，不要出现水印和字幕。
口型和口播对齐，说话声清晰，没有背景音乐。
```

**后期会做什么**：竖屏“视频即世界”版式，配色跟画面一致（近黑底、冰青线框、橙色只给“确定”的数字）。标注卡做成全息深色板（细边框、角标、数字从乱码滚成真值），字幕放在深色板上，引线连到折纸纸鹤和摄影机；配乐用合成器的纯净脉冲加纸张折叠的细响。
