# FACTS

The demo "Installing Summer" shows no real-world facts: no real people, brands, products, operating systems, events or statistics. Every file name, dialog text and number on screen (for example `sunscreen.dll`, "about 1 afternoon remaining", "Sunset detected. Ignore?") is invented. If a later version adds a real-world fact (a date, a figure, a product), list it here with the claim, the official source URL and the quoted wording.
