# 事实核对：天空为什么是蓝的

| 片中说法 | 依据 | 核对状态 |
|---|---|---|
| 太阳光看着是白的，其实是七种颜色混在一起 | 牛顿棱镜实验，教科书常识 | 常识，未逐条查来源 |
| 光进入大气会撞上空气分子（散射） | 瑞利散射 | 常识 |
| 蓝光波长短，被散射得更多；红光波长长，几乎直穿 | 瑞利散射强度与波长四次方成反比（蓝光比红光强约 5～6 倍） | 片中只说"更多/几乎直穿"，没写倍数 |
| 紫光波长更短，却不是紫色天空；原因：①太阳光里紫光比蓝光少 ②眼睛对紫色不太敏感 ③高层大气吸收一部分 | 科普常见的三点解释 | **未对照原始文献**；图中的光谱柱状图和视觉灵敏度曲线是示意形状，不是实测数据 |
| 傍晚光走更长的路，蓝光半路被散掉，只剩红橙光 | 同一散射原理 | 常识 |
| 这是示意动画 | 光子、空气分子是拟人化画法，大小、数量、速度不按比例 | 已知 |
