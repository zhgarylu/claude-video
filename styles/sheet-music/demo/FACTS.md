# Facts shown in "Four Notes"

The film makes no claims about real people, works, brands or events. The only facts on screen are music-theory terms used as the lesson's vocabulary; each is defined here with a source. The notes themselves are an original composition (demo/score.js).

| On screen | Claim | Source |
|---|---|---|
| "repeat" | restating a motif unchanged | https://en.wikipedia.org/wiki/Repetition_(music) |
| "invert" | a melody inverted turns each interval upside down, keeping its rhythm | https://en.wikipedia.org/wiki/Inversion_(music) |
| "stretch" | augmentation: the same melody in longer note values (here exactly double) | https://en.wikipedia.org/wiki/Augmentation_(music) |
| "contrary motion" | two voices moving in opposite directions | https://en.wikipedia.org/wiki/Contrary_motion |
| "Moderato", quarter = 92 | a moderate tempo marking with a metronome number | https://en.wikipedia.org/wiki/Tempo |
| p, mp, mf, f, ff, hairpin, fermata | standard dynamic and expression marks | https://en.wikipedia.org/wiki/Dynamics_(music) , https://en.wikipedia.org/wiki/Fermata |
| notation shapes | SMuFL (Standard Music Font Layout) code points, Bravura font | https://www.smufl.org/ |
